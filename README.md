# Access Studio

Independent demo built by Vinil Polepalli (vinilpolepalli.com), inspired by the problem space Floracene (YC S26) works in. Not affiliated with or endorsed by Floracene.

Role-controlled internal tooling for a fictional clinic: a patient callback list with live field-level access rules per role (front desk / nurse / practice admin), restricted fields rendered explicitly, a synthetic audit log, and a tool-config view. All patients and records are synthetic; the access rules are a simplified illustration, not HIPAA compliance advice.

Static export of a Next.js app. Built with Claude Code.
